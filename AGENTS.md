# Zapret2_AutoTuner — правила для агентов

Приложение на C# (.NET 10, Avalonia), Windows и Linux. Подбирает стратегии
zapret2 (nfqws2/winws2) на ПК и экспортирует их в zapret2, nfqws2-keenetic и
zapret-gui. План работ — `docs/PLAN.md`.

## Справочники (читать до кода)

| Задача | Skill |
|---|---|
| argv движка, запуск winws2/nfqws2, WinDivert, nft, лимиты | `.claude/skills/nfqws2-engine` |
| функции `--lua-desync`, аргументы, генерация и проверка стратегий | `.claude/skills/nfqws2-lua` |
| классификатор блокировок, критерии успеха, перебор, объединение, мониторинг | `.claude/skills/dpi-diagnostics` |
| экспорт и импорт: zapret2, nfqws2-keenetic, zapret-gui, бандл | `.claude/skills/strategy-export` |

## Жёсткие правила

1. Только синтаксис nfqws2 (`--lua-desync=`). Никакого `--dpi-desync`.
2. Факты о движке берутся из исходников бандлимой версии zapret2. Если skill
   расходится с исходником, исправь skill в том же PR.
3. Каталог функций и аргументов — данные, а не код, и сверяется тестом с
   бандлимыми `lua/*.lua`.
4. Любая стратегия перед запуском проходит Validator.
5. Успех — это полная загрузка (L2/L3), а не handshake. Подбор — только на
   заблокированном ресурсе (baseline обязателен).
6. Привилегированные действия (движок, firewall, захват) — только в Agent.
   UI работает без прав. Правила firewall всегда снимаются при выходе.
7. Ничего не применяется на роутере или в zapret-gui без явного
   подтверждения пользователя. Телеметрии нет.
8. Экспортёры покрыты golden и round-trip тестами.
9. Тексты UI — на русском (основной язык) и английском.
10. Сторонние бинарники (zapret2, WinDivert, браузер Playwright и т.п.) берутся
    только из официальных источников их авторов: релизы апстрима, официальный
    CDN Playwright. Никаких зеркал и сборок третьих лиц.
